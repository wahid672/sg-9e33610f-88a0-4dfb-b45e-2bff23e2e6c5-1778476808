# DigiMart - Digital Marketplace Platform

## Vision
Modern marketplace untuk produk digital dengan sistem multi-seller, affiliate, dan auto-delivery. Target: creator economy Indonesia yang butuh platform profesional untuk monetisasi konten digital.

## Design
Referensi: lynk.id — clean modern SaaS aesthetic

**Color System:**
- `--primary: 160 84% 39%` (emerald-600 - trust & growth)
- `--background: 0 0% 98%` (cream-white - soft on eyes)
- `--foreground: 215 25% 27%` (slate-700)
- `--accent: 217 91% 60%` (blue-500 - interactive)
- `--muted: 220 13% 91%` (slate-100)

**Typography:**
- Heading: Sora (600, 700) — geometric modern
- Body: Inter (400, 500, 600) — mobile-optimized

**Style Direction:**
Premium SaaS meets creator economy — professional tapi approachable, mobile-first dengan smooth animations

## Features
- Multi-seller marketplace produk digital
- Affiliate system dengan tracking
- Tripay payment integration
- Auto-delivery system
- Seller dashboard & storefront
- Mobile-first responsive design
- JWT authentication multi-role
